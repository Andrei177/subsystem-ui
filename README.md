# Подсистема интеграции внешних приложений

Frontend-часть дипломного проекта: интерфейс для подачи и рассмотрения заявок на интеграцию внешних приложений в облачную платформу по утверждённым контрактам безопасности и совместимости.

## Описание

Система позволяет представителям внешних приложений создавать заявки на интеграцию, а администраторам — просматривать, анализировать и принимать решения по ним (одобрить / отклонить).

## Основной функционал

- Регистрация и авторизация пользователей
- Создание заявки на интеграцию (контракт)
- Просмотр списка своих заявок и детальной информации
- Админ-панель:
  - Список всех заявок
  - Детальный просмотр и принятие решения по заявке
- Защищённые роуты и обработка 401

## Стек

- **React 19** + **TypeScript**
- **Vite**
- **Zustand** (стейт)
- **Axios** (с interceptors)
- **React Router 7**
- **Tailwind CSS 4** + **Shadcn/ui** + **Radix UI**
- **Feature-Sliced Design (FSD)**

## Архитектура (FSD)
```text
src/
├── app/          # Провайдеры, роутер, глобальные стили
├── pages/        # Страницы (signin, signup, contract-request-create, admin-*)
├── widgets/      # Крупные композиционные блоки
├── features/     # Бизнес-фичи (auth, create-request, admin-contract-request-review и т.д.)
├── entities/     # Бизнес-сущности (user, request)
└── shared/       # UI-kit, api, lib, config
``` 
## Запуск

```bash
npm install
npm run dev
```
По умолчанию API ожидается на http://localhost:8081.
## Backend
Серверная часть написана на Java 21 + Spring Boot 4 (WebFlux) + PostgreSQL + Redis.
